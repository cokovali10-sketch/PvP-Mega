# PvP Mega

All-in-one PvP resource pack for Minecraft Java **26.2** (Fabric, no mods required).

## Contents (single pack, priority top → bottom)

- **Short swords** — all 8 sword types shortened for visibility
- **Medium crits** — visible but compact critical-hit star (custom drawn)
- **Soft particles** — explosions removed, glitter/potion/generic reduced, sweeps small
- **Full grass** — grass sides use top texture (Fast Better Grass models)
- **Pigpack design** — inventory, buttons, items, entities (no blocks, no swords, no crit override)
- **Clean overlays** — no pumpkin blur, no spyglass ring, lightened water/powder-snow/nausea
- **Realistic Sky** — photorealistic HD skybox (day/night/sunset/stars) via Nuit-compatible OptiFine format
- **PvP tweaks** — low fire, low shield, clear lava, readable nether lava
- **Dark UI + icons + animated extras** (non-block parts only)

Vanilla kept: all block textures (except fire/lava), crosshair (works with CrosshairIndicator), skies fall back to vanilla without Nuit.

## Install

1. Put `PvP Mega.zip` into `resourcepacks/`
2. Enable it (top priority). Requires **Nuit** mod for the custom sky, everything else works vanilla.

## Build

Merged from: Pigpack, Short Swords (Oculie), Small Particles, Reduced Particles,
Fast Better Grass, Low Fire, Low Shield, Clear Lava, Netherite Lava Mining,
chrissi's Essentials, Icons, Default Dark Mode, Spunky Animated, Dramatic Skys,
Realistic Sky. Plus custom crit/overlay work. See `pack.mcmeta` (format 88).
